# Search an Element in a List

## Explanation

This Python program searches for a specified element in a list and determines whether the element is present.

## Problem Statement

Write a Python program to input a list of numbers and search for a given number in the list.

## Features

* Accepts multiple numbers.
* Accepts a search element.
* Checks whether the element exists.
* Displays the search result.

## How It Works

1. Read numbers from the user.
2. Store them in a list.
3. Read the element to search.
4. Check whether the element is present using the `in` operator.
5. Display the result.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `split()`
* `map()`
* `int()`
* `in` operator

## Program Flow

Input List → Input Search Element → Search List → Display Result

## Sample Input

```text
10 20 30 40 50
30
```

## Sample Output

```text
30 is present in the list.
```
